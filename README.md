# Windfarm-Desgin
Part A: Develop and evaluate a method for selecting turbines and cable connections that meet an energy target at low investment cost.
Part B: Extend your method and evaluation to consider landscape impact and examine the trade-off between cost and scenic disruption.
Provided files: Region A and Region B data, a Python notebook, and code for reading the data, solving a baseline MILP, and checking the returned solution.
